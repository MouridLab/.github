# MouridLab community health files

Ce dépôt contient le profil public multilingue de MouridLab et les règles communautaires héritées par les dépôts qui ne définissent pas leurs propres fichiers.

Les documents dans `profile/` alimentent la page de l’organisation. Les modèles et politiques à la racine de `.github/` constituent les valeurs par défaut de la communauté.
